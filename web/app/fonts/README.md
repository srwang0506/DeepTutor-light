# DeepTutor typefaces

The original DeepTutor UI uses Geist for interface text and Lora for serif headings.
These Latin variable-font subsets were retained from the original local Next.js font cache,
and are bundled here so production builds and local use do not fetch a font CDN.
Chinese text continues to use the declared system font fallbacks.

Upstream font sources and licenses:

- Geist: https://github.com/google/fonts/tree/main/ofl/geist
- Lora: https://github.com/google/fonts/tree/main/ofl/lora

Each family includes its upstream SIL Open Font License.
