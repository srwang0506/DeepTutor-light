个人学习与科研工作台 · Studio

产品入口
今日 / 资料库 / 项目保留为三个主要入口。资料库中的原件按内容哈希保存，论文作品、具体版本和文件分别管理；项目中的证据、实验、稿件和连接相互隔离。工作区记忆仍按“自己拥有 + 明确选择的其他工作区”检索。

远程工作区
从项目 → 远程工作区添加 SSH 或 GitHub 连接。
SSH 使用本机已经配置的别名与认证；只登记允许读取的目录，不上传私钥。服务器需要 Python 3。连接检查、目录浏览、固定仓库检查、文本读取采用固定协议，没有任意命令执行入口。主机校验保持开启，不使用密码交互或代理转发。
GitHub 使用本机 gh 登录，并将读取固定到 commit。连接或范围撤销后停止新读取；历史快照作为已取得的来源保留。
读取到的 manifest，以及 MLflow、W&B、TensorBoard 的结构化 JSON 导出，可转为待核对实验草稿。历史运行 commit 与当前仓库 HEAD 分开，文件声明成功不自动记为已验证成功。普通日志不猜测指标。缺失信息明确展示。
当前版本没有远程启动训练、远程写文件、GPU 调度或上述实验平台的在线 API 同步。

文献与证据
PDF、BibTeX、RIS、CSL-JSON 入库；OpenAlex、Crossref、arXiv 的检索条件、分页、原始响应与失败状态保存为快照。RSS 与已保存检索默认手动刷新，可开启运行期间的定期刷新。每次刷新保持原年份、排序与来源设置。外部来源不可用时，仍可读本地原件和记录。
证据绑定具体版本、原件哈希、物理页和引句；指标只有明确的同一评估协议才可比较。未知字段相同不会被当成协议一致。表格/图形固定输入快照并记录依赖，来源变化后相关稿段会提示重新检查。

论文写作
本地 Git 工作树中的多文件 TeX 为主稿，编辑采用内容哈希并发检查、自动保存与恢复日志。文件改动冲突时显示保存前、待保存和磁盘版本。
论文自己的 .bib 保留原引用键；从资料库加入的新条目写入 studio-references.bib，需要放入模板原有书目命令。
AI 修改只发送选区、明确勾选的来源摘要、引用键和该项目的术语/风格偏好。每个项目默认只允许本机写作模型；开启云端写作后可以使用现有 Codex OAuth 登录。生成结果为建议，需要审阅后接受。数字、单位、公式、引用、否定、范围与因果变化有单独提示；该规则检查不等同于事实核查。
编译为持久化后台任务，可取消与使用原始输入重试。中断任务明确标记，编译失败保留上一成功 PDF。macOS 使用已安装的 latexmk 与 OS 沙箱，不启用 shell escape；其他平台没有对应沙箱时仍可编辑，但不开放不隔离的编译。
投稿源文件包采用白名单与成功构建快照。审稿记录可连接投稿、依据与实际修改位置。

笔记复习
基础闪卡使用稳定身份与内容版本。小幅空白修改保留排期；实质变更要求本人选择保留排期或重新学习。今日使用同一份复习进度，翻开答案不记作已学会。旧 Anki 标识保持兼容。

连续使用与资料交换
Zotero 支持元数据增量同步、游标、删除标记、失败重试与撤权；附件原件仍需明确导入。实验页可以持续读取一个本地 JSONL 日志，分页查看原始事件与曲线，日志中的“成功”保持为来源声明。
综述可冻结问题、检索式与纳排标准，分别进行题录和全文筛选，提取字段连接对应版本的原文证据。题族可按概念、解法与条件人工复核；候选匹配不会自动证明题目等价。
工作区支持加密文件迁移：导入前查看冲突并逐项选择，保留聊天、学习记录、记忆、原件、历史与依赖；凭据、连接、记忆访问授权和运行任务不随包迁移。它是文件交换，不是后台云同步。
PDF 和已有题目可以明确保存到本浏览器离线区，断网继续阅读、保存答案，联网后主动提交；重复提交不会重复记分，离线独立性保留未知。

质量与当前边界
已补齐本轮界面语言资源，仓库使用完整 ESLint、类型、架构、组件与接口检查。质量评测支持冻结任务集、隔离开发和测试题族/论文、逐题运行与可导出的回执。标准答案不发送给模型；未知费用与估算用量明确标注。
公开 MMLU 的 90 道配对任务经现有 Codex OAuth 实测答对 85 道。这不是 HOI 论文精读、开放式教学或独立认证的替代品。
MLflow/W&B/TensorBoard 仍是文件交换适配器；未连接真实 SSH/GPU 服务器和真实 Zotero 私人库进行验收。具体用法、数据格式、迁移限制与验收边界见 docs-for-dev/STUDIO_REVIEW3.md。

本地验收
SSH 采用独立 mock-bin/ssh 夹具，只访问本机合成仓库；未连接真实服务器、未执行训练。本机工作区的预览数据和代码正式运行数据分开。
测试：tests/studio、tests/notes、项目隔离与权限回归；前端测试包含笔记卡片、今日推荐、Studio 请求传输；另有实际 TeX 沙箱测试和备份异地路径恢复验收。
